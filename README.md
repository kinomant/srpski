## ЧАСТЬ 1. Новые режимы тренировки

На главном экране под счетчиком билетика добавляется блок быстрых режимов:

```
[ 🎯 Входной тест ]   [ 🔄 Работа над ошибками ]   [ ⚡ Блиц-экзамен ]   [ 🗂️ Карточки ]
```

1. **🎯 Входной тест уровня (Placement Test):**
   * 20 вопросов (по 5 на A2, B1, B2, C1).
   * Выдаёт вердикт: *«Твой уровень — B1. Рекомендуем начать с Линии 2, уроки Линии 1 можно открыть для повторения»*.
2. **🔄 Работа над ошибками:**
   * Сканирует весь `localStorage` на наличие статуса `false` (ошибки, допущенные в любых уроках).
   * Собирает из них персональный тест. При правильном ответе статус ошибки снимается.
3. **⚡ Случайный блиц / Экзамен:**
   * Экспресс-раунд из 15 случайных вопросов по всей базе открытых уроков на время или на очки.
4. **🗂️ Карточки с интервальным повторением (SRS):**
   * Повторение слов и выражений из Лексикона с алгоритмом забывания (Leitner box).

## ЧАСТЬ 2. Мультимедиа: Аудио, Видео и Микрофон

1. **🎙️ Проверка произношения (Speech Recognition):**
   * В карточках с сербскими предложениями добавляется кнопка с микрофоном 🎙️.
   * Ученик наговаривает фразу ➔ браузер (`webkitSpeechRecognition`, язык `sr-RS`) транскрибирует речь и сравнивает её с эталоном с точностью до слова.
